# PaperOrchestra Integration Guide: Automated Research Paper Generation for Project LEO / HYPER

## 1. Executive Summary & Value Proposition

To supercharge productivity, research scalability, and automated documentation across **Project LEO / HYPER**, Google Cloud AI Research's **PaperOrchestra** framework (`arXiv:2604.05018`) has been integrated directly into the repository.

### Key Capabilities Unlocked
- **Automated Camera-Ready Paper Generation:** Automatically turns empirical execution logs and hardware verification ledgers into submission-ready LaTeX manuscripts formatted for premier AI conferences (ICLR 2025, CVPR 2025, and IEEE).
- **Multi-Agent Orchestration:** Deploys specialized LLM agents for each phase of academic writing:
  - `OutlineAgent`: Synthesizes global section hierarchy, narrative flow, and core theoretical arguments.
  - `HybridLiteratureAgent`: Discovers and synthesizes relevant literature (via Semantic Scholar / Gemini).
  - `SectionWritingAgent`: Drafts individual sections referencing mathematical formulations and empirical tables.
  - `ContentRefinementAgent`: Iteratively polishes grammar, style, conference guidelines compliance, and coherence.
  - `PlottingAgent`: Translates raw experimental numbers into publication-quality figures and plots.
- **Automated Empirical Synthesis Bridge (`backend/paper_orchestra_bridge.py`):** Automatically extracts live metrics from `reports/FUNCTIONAL_REPLACEMENT_AUDIT.json` and `reports/UNIVERSAL_FABRIC_BENCHMARKS.json`, mapping them directly into PaperOrchestra's `raw_materials/` format (`idea_sparse.md`, `experimental_log.md`).

## 3. Quickstart & CLI Commands

### 3.1. Dry-Run Verification (Zero API Cost, Instant)
Generates the complete paper skeleton, synthesizes `raw_materials/` from the latest live audit, copies the conference template, and creates `outline.json` without remote LLM calls:
```bash
python scripts/generate_paper_orchestra.py --template iclr2025 --dry-run --output-dir reports/paper_draft
```

### 3.2. Full Multi-Agent Synthesis (With Gemini API Key)
Generates a complete camera-ready paper using Gemini models:
```bash
# Set Gemini API key
export GEMINI_API_KEY="your-api-key"

# Generate ICLR 2025 paper
python scripts/generate_paper_orchestra.py --template iclr2025 --output-dir reports/iclr2025_submission

# Generate CVPR 2025 paper
python scripts/generate_paper_orchestra.py --template cvpr2025 --output-dir reports/cvpr2025_submission
```

### 3.3. Running the Interactive Streamlit UI
```bash
streamlit run paper_orchestra/frontend/app.py
```

## 4. Programmatic Python API

You can also use PaperOrchestra directly inside Python scripts or automated benchmarks:

```python
from backend.paper_orchestra_bridge import PaperOrchestraBridge
from pathlib import Path

bridge = PaperOrchestraBridge()

# 1. Prepare raw materials from latest audit
materials = bridge.prepare_raw_materials(output_dir=Path("reports/my_paper"))
print(f"Idea doc: {materials['idea_path']}")
print(f"Experimental log: {materials['experimental_log_path']}")

# 2. Run generation
result = bridge.run_generation(
    output_dir=Path("reports/my_paper"),
    template_name="iclr2025",
    dry_run=True, # or False for live LLM agents
)
print("Generated writeup at:", result["latex_writeup_dir"])
```
