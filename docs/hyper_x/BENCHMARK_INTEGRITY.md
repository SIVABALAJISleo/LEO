# HYPER-X Benchmark Integrity & Anti-Faking Protocol

## 1. Ground Rules for Scientific Verification

1. **Mandatory Dynamic Hardware Fingerprinting**:
   - Every benchmark report must include a cryptographic hardware fingerprint generated by `HardwareFingerprint.detect()`.
   - If the host machine is an `Intel Core i5-13420H` (current host) and legacy tables cite `Intel Core i5-12450H`, the system must explicitly set:
     `host_mismatch = True` and output badge `TARGET_MISMATCH`.
2. **Explicit Telemetry Labeling**:
   - Energy calculations based on nominal TDP must be tagged `ESTIMATED_POWER`, never `MEASURED_POWER`.
   - Wall-clock latencies must be measured with `time.perf_counter()` over multiple warm runs, separating cold-cache effects from warm-cache benchmarks.
3. **No-Free-Lunch Discipline**:
   - Benchmarks must include dense random Gaussian matrices with full rank.
   - On full-rank unstructured inputs, the compiler must output:
     `"No verified computational wormhole discovered."`
   - Hardcoded 100% parity claims are strictly prohibited.
4. **Independent Verification Protocols**:
   - Exact mode: deterministic bitwise comparison.
   - Numerical tolerance mode: Freivalds $O(N^2)$ randomized probabilistic verification with confidence $1 - 2^{-k}$ ($k \ge 15$).
   - Perceptual mode: SSIM ($\ge 0.92$) and PSNR ($\ge 28$ dB) across reconstructed visual frames.
5. **Anti-Leakage Sealed Holdouts**:
   - Cryptographically sealed holdout datasets evaluated blind.
   - AST inspectors ensure candidate functions do not inspect, print, or store reference buffers.
