## Subsystem Architecture Details

The V30 framework utilizes 15 co-dependent sub-engines to guarantee reliability and low compute footprints:

### 1. World Model Engine (`worldModelEngine.ts`)

Builds environmental abstractions utilizing topological nodes (rooms, zones, landmarks, events) linked directly to GraphRAG citations.

### 2. Dreamer Planning Engine (`dreamPlanningEngine.ts`)

Simulates prospective future trajectories, ranks decision rewards, and handles counterfactual logic to predict alternative outcomes.

### 3. Scientific Discovery Engine (`scientificDiscoveryEngine.ts`)

Synthesizes empirical datasets to generate, catalog, and rank hypotheses backed by evidence citation chains.

### 4. Symbolic Regression Engine (`symbolicRegressionEngine.ts`)

Extracts mathematical relationships from numerical logs and formats them into human-readable algebraic formulas (inspired by PySR).

### 5. Formal Reasoning Engine (`formalReasoningEngine.ts`)

Performs logical validation checks, formal proofs verification, and theorem compiling using strict logical lemmas (inspired by Lean4).

### 6. Causal Reasoning Engine (`causalReasoningEngine.ts`)

Maps directed Cause-Effect linkages and conducts intervention analysis (Do-calculus) to distinguish correlation from causation.

### 7. Physics-Informed Validation Engine (`physicsValidationEngine.ts`)

Validates model suggestions against physical constraints (motion velocity limits, G-force tolerance, energy thresholds) to reject invalid output actions.

### 8. Conformal Uncertainty Engine (`uncertaintyCalibrationEngine.ts`)

Computes statistical margins of error and confidence intervals to tag predictions into Verified, Likely, Uncertain, or Unknown classes.

### 9. Analogical Reasoning Engine V2 (`analogicalReasoningEngineV2.ts`)

Adapts resolved historical patterns to unknown target domains using structural similarity transfers.

### 10. Long-Tail Edge Case System (`edgeCaseDiscoveryEngine.ts`)

Catalogs rare failure modes, safety alerts, and adversarial injections to trigger loop remediation strategies.

### 11. OpenVINO Optimization Layer (`openvinoOptimizationEngine.ts`)

Optimizes local execution profiles, supporting INT8 quantizations and dynamic iGPU thread allocations.

### 12. Model Cascade Engine (`adaptiveModelCascade.ts`)

Directs query fallback escalations (Tiny 1B -> Small 7B -> Medium 13B -> Large 70B), invoking large-parameter models only for high-complexity prompts.

### 13. Reality Alignment Network (`realityAlignmentNetwork.ts`)

Measures performance distances between simulated projections and real-world results to adjust system trust rates dynamically.

### 14. Frontier Testing Lab (`frontierTestingLab.ts`)

Stress-tests logic pipelines using red-team prompt injections and contradictory scenarios.

### 15. Frontier Improvement Loop (`frontierImprovementLoop.ts`)

Coordinates the automated convergence cycle: `Measure -> Detect Weakness -> Propose Fix -> Validate -> Benchmark -> Deploy`.
